# AI Agent Harnesses for Mechanical CAD, Physical Product Design, and Full-Stack Hardware

Research date: 2026-10-24. About 17 tool calls. Many startup claims come from vendor or aggregator blogs and are flagged as such.

## Research: CAD-generation agents, MCP servers, and benchmarks

### Takeaway
Academic text-to-CAD has settled on generating code, mostly CadQuery Python. Fine-tuning and RL with geometric rewards (CAD-Coder, Text-to-CadQuery, CAD-Recode) improve one-shot accuracy. Agentic loops that render, critique with a VLM and re-run, or add FEA, help noticeably. Even so, 2026 benchmarks show frontier agents (Claude Code / Opus 4.7, Codex / GPT-5.5) failing hard on complex multi-part, requirement-heavy briefs. MCP servers for FreeCAD, Fusion, Onshape and Blender exist and are widely used, but reviewers describe them as unreliable on complex models and assemblies.

### Cited Findings
**Code-CAD generation models (2024–2025)**
- CADCodeVerify (ICLR 2025, arXiv Oct 2024). A VLM generates CAD code, renders it, asks itself verification questions about the render and fixes the code. This is an early render-and-look loop. It introduced the CADPrompt benchmark: 200 prompts with expert-written code. On GPT-4 it cut point-cloud distance by 7.30%. The compile-success gain is reported as 5.0% in the ICLR listing and 5.5% in arXiv v2, so the two versions conflict. — [ICLR 2025](https://www.iclr.cc/virtual/2025/poster/30576); [arXiv v2](https://arxiv.org/html/2410.05340v2)
- CAD-Coder (NeurIPS 2025, arXiv 2505.19713). Text-to-CadQuery via SFT, then RL with a Chamfer-distance geometric reward plus chain-of-thought. Dataset of 110K text–CadQuery–3D triplets. — [NeurIPS 2025](https://neurips.cc/virtual/2025/poster/118098); [proceedings](https://proceedings.neurips.cc/paper_files/paper/2025/hash/564a224e88f2490f3c1deaae877d37e3-Abstract-Conference.html)
- Text-to-CadQuery (Xie & Ju, arXiv 2505.06507, May 2025). Adds CadQuery code to DeepCAD/Text2CAD samples, for about 170K text–CadQuery pairs. Fine-tuned models from 124M to 7B parameters, with gains as scale grew. — [arXiv](https://arxiv.org/pdf/2505.06507)
- Text2CAD supplies multi-level natural-language annotations on top of DeepCAD. DeepCAD has 178,238 Onshape-derived sketch-and-extrude command-sequence models. — [Text-to-CadQuery paper](https://arxiv.org/pdf/2505.06507)
- CAD-Recode (Rukhovich et al., Univ. Luxembourg; arXiv Dec 2024, ICCV 2025). Point cloud to CadQuery Python code, using a Qwen2-1.5B decoder and a point-cloud projector. Trained on 1M procedurally generated CAD sequences. At inference it samples multiple programs and keeps the one with the lowest Chamfer distance. Reported state of the art on DeepCAD, Fusion360 and CC3D. — [ICCV 2025 PDF](https://orbilu.uni.lu/bitstream/10993/67036/1/CADRecode_ICCV_2025.pdf); [supplement](https://openaccess.thecvf.com/content/ICCV2025/supplemental/Rukhovich_CAD-Recode_Reverse_Engineering_ICCV_2025_supplemental.pdf)
- CADDesigner (arXiv 2508.01031, Aug 2025). A general-purpose LLM agent for conceptual CAD that takes text plus freehand sketches and generates CAD code. — [arXiv](https://arxiv.org/html/2508.01031v1)

**Agentic and feedback-loop papers (2026)**
- "Self-Improving CAD Generation Agents with FEA as Feedback" (Son et al., arXiv 2605.17448, May 2026, WIP). Task: a free-form engineering brief to a fully assembled multi-part STEP file, validated by FEA. Supervision comes from a text "blueprint" schema plus a 21-view image renderer. In first-attempt runs, Codex (GPT-5.5) and Claude Code (Opus-4.7) agents produced zero strict-passing artifacts. The best configuration met only about 20% of typed requirements. With the feedback tools, GPT-5.5/xhigh Box-IoU rose from 0.444 to 0.592 on S2O and from 0.397 to 0.505 on Fusion360. — [arXiv](https://arxiv.org/abs/2605.17448)
- "Foundation Models for Automatic CAD Generation" (de Curtò et al., arXiv 2607.05573, Jul 2026). The LLMForge framework uses JSON-schema validation and multi-round refinement. It has two loops. IterTracer uses a ray-traced render scored by silhouette IoU, hole visibility and similar metrics. IterVision uses Qwen2.5-VL-72B as a VLM critic on renders. The benchmark is 97 problems across plates, boxes, flanged cylinders and L-brackets. The top four of seven open models clustered at 0.885–0.890, with 98.97% mesh success. Rotationally symmetric parts showed the largest gap between visual and semantic scores. — [arXiv](https://arxiv.org/abs/2607.05573)
- "Clarify Before You Draw" (arXiv 2602.03045, Feb 2026). A proactive agent asks clarifying questions before generating CadQuery. It notes most text-to-CadQuery systems are one-shot. — [arXiv](https://arxiv.org/pdf/2602.03045)
- Also in 2026 arXiv, titles only and not read: CADIR, a cross-backend editable intermediate representation for agentic CAD (2608.00891). CADENA, stepwise CAD reverse engineering (2608.00799). Test-time scaling via verifier-free consensus selection (2608.09706). — [CADIR](https://arxiv.org/pdf/2608.00891); [CADENA](https://arxiv.org/pdf/2608.00799); [TTS](https://arxiv.org/pdf/2608.09706)
- AgentsCAD (arXiv 2607.02448, Jul 2026). A multi-agent design-for-manufacturing system for FDM parts. A Design Reasoner agent proposes CAD changes and a CAD Code Verifier evaluates them in a loop. Outputs are validated by actually printing them. — [arXiv](https://arxiv.org/html/2607.02448)
- eschmitt88/agentic-3d-design (GitHub, in progress). Code-CAD agent with a verification ladder: geometry validity, then printability, then rendered-image review, then FEA for load-bearing parts. The author reports single-pass generation is "far worse" than the loop. Physical printing is listed as future work. — [GitHub](https://github.com/eschmitt88/agentic-3d-design)

**Benchmarks**
- Text2CAD-Bench (arXiv 2605.18430, May 2026). 600 human-curated examples across 4 levels: L1–L2 basic geometry, L3 complex topology and freeform surfaces, L4 real-world non-mechanical domains. Each has a lay-geometric prompt and an expert-procedural prompt. Performance is "reasonable on basic geometry but degrade[s] substantially on complex topology." In its ablation, CadQuery code beat command-sequence outputs on both validity and geometric accuracy. — [arXiv abs](https://arxiv.org/abs/2605.18430); [HTML](https://arxiv.org/html/2605.18430v1)
- Other benchmarks are cited but were not read: CADPrompt (in CADCodeVerify), CADTests (2605.07807), BenchCAD (2605.10865), MUSE (2605.28579). — [Text2CAD-Bench/search listing](https://arxiv.org/html/2605.18430v1)

**MCP servers (agent-to-CAD bridges)**
- FreeCAD: neka-nat/freecad-mcp is described as the most popular open-source engineering CAD MCP server. It lets Claude Desktop drive a live FreeCAD. Reported star counts vary from about 1.8K to 2.7K. — [buildcad.ai comparison](https://buildcad.ai/guides/cad-mcp-servers); [mcp.directory guide](https://mcp.directory/blog/freecad-mcp-complete-guide-2026)
- Fusion 360: Autodesk ships an official local MCP server that runs next to Fusion. Autodesk itself notes it is not yet reliable for complex models or full assemblies. A community server by JustusBraitinger has 27 tools including STEP/STL export, and faust-machines has another. — [buildcad.ai](https://buildcad.ai/guides/cad-mcp-servers); [glama listing](https://glama.ai/mcp/servers/faust-machines/fusion360-mcp-server)
- Onshape: an official server in early access writes, tests and searches docs for FeatureScript custom features rather than doing general modelling. The community BLamy/onshape-mcp uses the REST API but is reportedly stale since April 2025. — [buildcad.ai](https://buildcad.ai/guides/cad-mcp-servers); [TechDraw AI](https://techdrawai.com/blog/cad-mcp-servers). The user's own environment has the official Onshape MCP installed, with tools such as create_feature_studio, test_featurescript and search_featurescript_documentation.
- Roundups also list Blender, AutoCAD, KiCad, SolidWorks, OpenSCAD and build123d MCPs. — [Snyk: 9 CAD MCP servers](https://snyk.io/articles/9-mcp-servers-for-computer-aided-drafting-cad-with-ai/); [ChatForest review](https://chatforest.com/reviews/cad-3d-modeling-mcp-servers/)

### Inferences
- The dominant 2026 harness pattern is LLM → CadQuery/build123d/OpenSCAD code → execute (the kernel returns errors) → render multi-view → VLM self-critique → optional FEA → revise. CadQuery wins because LLMs already know Python, and Text2CAD-Bench directly supports that.
- The jump from single parts to assemblies plus requirements is where agents collapse. FEA-feedback results such as roughly 20% of requirements met and zero strict passes show that "a general coding agent plus a CAD MCP" is not yet a mechanical engineer.

### Gaps
- No primary source was read for "LLM4CAD" or "Blueprint/MechAgents". MechAgents (Ni & Buehler, 2023) is a known multi-agent elasticity/FEA paper from memory, but it was not verified in this session.
- The Text2CAD venue (NeurIPS 2024) was not confirmed from a primary source.
- I found no head-to-head leaderboard comparing Claude, GPT and Gemini on a common CAD benchmark. Headline model scores for Text2CAD-Bench were not extracted.

## Startups: who is actually agentic

### Takeaway
Most commercial "AI CAD" tools in 2026 are copilots: autocomplete, scan or drawing to CAD, search. Few are agents. The ones with real agent loops are Zoo's Zookeeper (which uses engine tools to inspect, snapshot and debug geometry) and Adam (which edits feature trees inside Onshape, Fusion and SolidWorks). Independent tests still show all text-to-CAD tools failing on medium-to-high complexity parts.

### Cited Findings
- **Zoo (formerly KittyCAD).** Zookeeper is a conversational CAD agent in Zoo Design Studio. It has research and reasoning plus "engine-level tools to inspect, snapshot, and debug geometry," can delegate manufacturability checks, and iterates on existing designs. An enterprise tier offers fine-tuning on proprietary data. Zoo's CAD language is KCL. — [zoo.dev/text-to-cad](https://zoo.dev/text-to-cad). Sources conflict on output: Leo AI's (competitor) blog calls Zoo mesh/STL-based, while other 2026 guides say it produces editable B-rep solids exportable as STEP. — [Leo blog](https://www.getleo.ai/blog/text-to-cad-tools-comparison-guide) vs. [neural4d / cadcrowd roundups](https://blog.neural4d.com/comparisons/best-ai-cad-generator/). One independent test had Zoo pass a cylinder but fail a gear and a manifold. — [Xometry test](https://xometry.pro/en/articles/text-to-cad-tools-test/)
- **Adam (formerly AdamCAD, YC).** Described in 2026 as a CAD copilot that edits feature trees and runs BOM, sourcing and documentation workflows directly inside Onshape, Fusion and SolidWorks. Earlier versions were a browser tool that generated CadQuery/OpenSCAD with Parametric and Creative modes. In Leo's test, Adam's code for a gearbox housing would not compile because of bad Booleans. — [roundup via search](https://thecadhub.com/blog/ai-cad-software/); [Leo blog](https://www.getleo.ai/blog/text-to-cad-tools-comparison-guide). Note: this is not verified on Adam's own site.
- **Spectral Labs SGS-1.** Native B-rep generation. Simple STEP files open cleanly in SolidWorks and Fusion. Multi-pocket housings were "unusable", fillets lost tangency and planar faces warped. — [Leo blog](https://www.getleo.ai/blog/text-to-cad-tools-comparison-guide)
- **Backflip AI.** Founded late 2024 by Markforged co-founders Greg Mark and David Benhaim. $30M Series A led by a16z and NEA. Converts scans and meshes to parametric feature-tree CAD as a Fusion add-in and web app, from $20 per month. In September 2026 it launched 2D-drawing and photo to 3D in Fusion. — [VoxelMatters](https://www.voxelmatters.com/backflip-ai-launches-cad-copilot-that-turns-3d-scans-into-editable-models/); [Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/backflip-ai-converts-2d-engineering-130000356.html); [mlq.ai](https://mlq.ai/news/backflip-ai-launches-scan-to-cad-tool-inside-autodesk-fusion/)
- **Hestus (YC).** "Autocomplete for CAD" inside Autodesk Fusion that predicts sketch steps. Raised a $7.4M seed led by Insight Partners, for $8.9M total; an earlier $1.5M round was led by Liquid2 and Rock Yard. — [hestus.co](https://www.hestus.co/); [Unite.AI](https://www.unite.ai/hestus-raises-7-4-million-seed-to-bring-ai-into-mechanical-engineering/); [R&D World](https://www.rdworldonline.com/hestus-secures-1-5m-seed-funding-to-streamline-cad-workflows-with-targeted-ai/)
- **Leo AI.** According to its own blog, it does not generate new geometry. It searches PDM/PLM vaults for reusable parametric parts and does engineering Q&A with cited sources. Other roundups describe it differently. — [Leo blog](https://www.getleo.ai/blog/text-to-cad-tools-comparison-guide)
- **Autodesk Project Bernini.** A research generative model, shown May 2024, that produces 3D from text, images or point clouds, focused on clean geometry and topology. It is not agentic. — [Axios](https://www.axios.com/2024/05/08/autodesk-ai-3d-models-bernini)
- **Flux.** Markets an "AI Hardware Engineer" agent for PCBs: brief, then part research with live distributor data, then schematic, layout and manufacturing files. A secondary source reports a $27M Series B led by 8VC in 2025 (unverified). — [yespress](https://yespress.io/flux); [Flux blog](https://www.flux.ai/p/blog/code-firmware-faster-with-ai)
- **EDA incumbents.** Siemens launched its Fuse EDA AI Agent in March 2026. Cadence's PCB agent "AuraStack" is due in 2026. Synopsys promises general availability of its agent portfolio by end of 2026. — [Tom's Hardware](https://www.tomshardware.com/tech-industry/semiconductors/the-state-of-agentic-ai-in-chip-design-tools-in-2026-cadence-synopsys-and-siemens-all-pitch-autonomous-engineers)
- **Hilstart** (YC listing) describes building "physical agent harnesses" so AI can debug, validate and ship hardware. **Simantic** offers hardware simulation for AI firmware development. — [YC hardware directory](https://www.ycombinator.com/companies/industry/hardware)

### Inferences
- "Agentic" in mechanical CAD in 2026 means one of two things. One is a model with tool access to a kernel (Zoo KCL, Onshape, Fusion APIs) that can query geometry and self-correct. The other is a scripting copilot. Scan-to-CAD (Backflip) and autocomplete (Hestus) are narrower ML products.
- Comparison blogs are mostly written by vendors (Leo, Neural4D, MeltflexAI), so treat relative rankings skeptically.

### Gaps
- Vizcom (industrial-design sketch to render) was not researched. Neither was any startup called "Spectral" beyond SGS-1, nor "Vitalize" or "Phaidra". Phaidra, as far as I know, does AI control for industrial facilities rather than hardware design, but I did not verify that this session.
- No primary sources from Adam's or Spectral's own sites. Funding for Adam, Zoo and Spectral was not verified.

## End-to-end hardware agents, robot design, and self-driving labs

### Takeaway
Physically closed loops exist, but they are narrow. Text2Robot (Duke, ICRA 2025) prints and walks real quadrupeds. BU's MAMA BEAR has printed and crushed more than 25,000 parametric structures using Bayesian optimization; that is not an LLM, and it set an energy-absorption record. CMU's LLM-3D Print has VLM agents fix live prints from layer camera images. Multi-domain "build the whole device" agent demos (MechFaber, Claude-driven KiCad boards) remain unbuilt or unfabricated. I found no verified case of an LLM agent autonomously doing enclosure CAD, PCB and firmware and producing a working, tested device.

### Cited Findings
**Robot morphology design**
- Text2Robot (Duke; arXiv 2406.19963; ICRA 2025, May 19–23, Atlanta). Text, then a generated model with joints, then evolutionary design plus RL training to walk, then the best design is 3D-printed (Creality CR-10 Smart Pro) and assembled with Hiwonder HTD-45H bus servos. Coverage reports a walking robot in about a day. So far it is limited to quadrupeds. — [arXiv](https://arxiv.org/pdf/2406.19963); [EurekAlert](https://www.eurekalert.org/news-releases/1080030); [WUNC Apr 2025](https://www.wunc.org/term/news/2025-04-25/text2robot-ai-3d-print-duke-robotics)
- RoboMorph (arXiv 2407.08626, Jul 2024). An LLM serves as the generative operator in an evolutionary loop, with RL-trained controllers evaluating morphologies. Simulation only. It matches or beats RoboGrammar, and the authors say manufacturing and sim-to-real remain open. — [arXiv](https://arxiv.org/pdf/2407.08626)
- RoboMoRe (arXiv 2506.00276, 2025): LLM co-design of morphology and reward, not read in detail. "LLMs for Model-Based Robot Design" (arXiv 2609.33423, Sep 2026) is a newer survey/method in the same line. — [RoboMoRe](https://arxiv.org/pdf/2506.00276); [2609.33423](https://arxiv.org/html/2609.33423v1)
- "An LLM-enabled Multi-Agent Autonomous Mechatronics Design Framework" (arXiv 2504.14681, Apr 2025). A multi-agent mech plus electrical plus software design framework. Only the title was seen; contents not verified. — [arXiv](https://arxiv.org/pdf/2504.14681)

**Self-driving labs and physical iteration**
- BU KABlab MAMA BEAR (Brown lab). Five FFF printers, a scale, an Instron press and a cobot. 11-parameter geometry gives more than a trillion designs. Bayesian optimization picks each next print. It has run near-continuously since 2021, testing more than 25,000 structures, and reached 75% energy-absorption efficiency against a prior record of about 71% (Nature Communications, May 2024). Classical BO, not an LLM. — [BU feature](https://ar.bu.edu/2024/ai/self-driving-lab); [Instron case study](https://www.instron.com/fr/resources/case-studies/boston-university-kablab); [Interesting Engineering](https://interestingengineering.com/innovation/us-army-robot-3d-prints-shock-absorbing-shape)
- LLM-3D Print (CMU; Additive Manufacturing, 2025). Layer images go to a VLM quality judge. Four LLM agents (supervisor, planners, executors) built in LangGraph adjust print parameters live through Klipper, Moonraker and Crowsnest, using in-context learning with no defect-dataset fine-tuning. CMU news (Feb 2026) calls it AI that "saves 3D prints in real time." — [ScienceDirect](https://www.sciencedirect.com/science/article/pii/S2214860425003926); [CMU news](https://engineering.cmu.edu/news-events/news/2026/02/06-ai-saves-3d-prints.html); [Fabbaloo](https://www.fabbaloo.com/news/llm-agents-step-into-the-3d-printer-control-loop)

**Multi-domain (mech + electrical + firmware) agent work**
- Diode Computers and Anthropic partnership (undated blog). Claude drafts PCB schematics in Zener, Diode's open Starlark-based HDL that renders to KiCad. Each module is SPICE-simulated, and Claude sees gain, bandwidth and stability margins and iterates. Static netlist checks catch floating pins and miswired rails. About 250 reference modules were produced in two weeks. Engineers sign off on everything. Diode claims timelines shifted from months to weeks but gives no numbers. — [Diode blog](https://blog.diode.computer/anthropic-partnership)
- MechFaber (Reddit user "SpeedyBrowser45"; Wccftech, Sep 22, 2026). A desktop app where specialized Claude Code agents handle research, calculations, CAD (querying the kernel for dimensions), FEA, electronics (Pi 5 for LiDAR, Teensy for motor control, power and runtime budgets) and firmware tested in a loop against a physics engine with ramp and obstacle scenes. It produced a 12-actuator, 99-part quadruped. "Nothing has been built as yet." — [Wccftech](https://wccftech.com/claude-code-designs-12-actuator-quadruped-robot-99-parts-firmware-simulation/); [Reddit](https://www.reddit.com/r/ClaudeAI/comments/1wmpd78/i_built_a_desktop_app_where_claude_code_designs/)
- Claude Code with KiCad MCP (JLCPCB tutorial). A two-layer XL4015 buck converter with 0 ERC and 0 DRC errors, not yet fabricated or bench-tested. — [JLCPCB](https://jlcpcb.com/blog/kicad-mcp-how-to-design-a-pcb-with-claude-code). A separate test had Claude Code in EasyEDA Pro rebuild a 47-part schematic from a PDF and route a two-layer board. The human still handled sourcing, approvals and clearance and thermal review. — [JLCPCB](https://jlcpcb.com/blog/claude-code-pcb-design)

### Inferences
- Physical loops close fastest where the design space is low-dimensional and parametric and the test is cheap and automatable: crush tests, walking gait, print-defect images. LLMs add value as the generator or controller, but classical BO still runs the best-documented physical self-driving lab.
- Multi-domain agent harnesses (MechFaber, Diode) close the loop in simulation (physics engine, SPICE, FEA, DRC). Physical verification remains a human-gated step.

### Gaps
- I found no verified LLM-agent system that revises CAD from physical test data of the printed part, measured load or fit. AgentsCAD prints only to validate, and the CMU work adjusts print parameters, not geometry.
- I could not verify "Vitalize" as an AI hardware-engineering startup. No evidence was found for a "Phaidra" hardware-design product.

## How the loop closes: render-and-look, simulation, physical test

### Takeaway
There are three feedback tiers in use. (1) Kernel or execution feedback: compile errors and invalid solids. (2) Render-and-look: multi-view renders judged by a VLM or by analytic image metrics. (3) Simulation: FEA, SPICE, physics engines. Physical testing is rare and nearly always done by fixed-purpose rigs (Instron, printer camera) rather than a general agent. Iterative loops consistently beat one-shot generation, but they do not rescue complex assemblies.

### Cited Findings
- Execution plus self-verification: CADCodeVerify renders and asks itself visual verification questions, giving a 7.3% point-cloud distance reduction on GPT-4. — [arXiv v2](https://arxiv.org/html/2410.05340v2)
- Sampling plus geometric selection: CAD-Recode samples several programs and picks the lowest Chamfer distance. CAD-Coder uses Chamfer distance as an RL reward. Verifier-free consensus selection (2608.09706) is a newer test-time-scaling variant. — [CAD-Recode supp.](https://openaccess.thecvf.com/content/ICCV2025/supplemental/Rukhovich_CAD-Recode_Reverse_Engineering_ICCV_2025_supplemental.pdf); [CAD-Coder](https://neurips.cc/virtual/2025/poster/118098); [TTS paper](https://arxiv.org/pdf/2608.09706)
- Render and VLM critic: IterVision (Qwen2.5-VL-72B critic) and IterTracer (analytic silhouette and hole metrics). — [arXiv 2607.05573](https://arxiv.org/abs/2607.05573). A 21-view renderer is used as an agent tool. — [arXiv 2605.17448](https://arxiv.org/abs/2605.17448). Zoo Zookeeper's "snapshot" tool is a commercial equivalent. — [zoo.dev](https://zoo.dev/text-to-cad)
- FEA feedback: Box-IoU gains of about 0.1–0.15, but only about 20% of requirements met and zero strict passes first time for frontier coding agents. — [arXiv 2605.17448](https://arxiv.org/abs/2605.17448). The agentic-3d-design ladder runs validity, then printability, then render review, then FEA. — [GitHub](https://github.com/eschmitt88/agentic-3d-design)
- Electrical simulation: SPICE results fed back to Claude in Diode's Zener pipeline. — [Diode](https://blog.diode.computer/anthropic-partnership). Physics-engine firmware testing in MechFaber. — [Wccftech](https://wccftech.com/claude-code-designs-12-actuator-quadruped-robot-99-parts-firmware-simulation/)
- Physical: an Instron crush, then BO (MAMA BEAR). — [BU](https://ar.bu.edu/2024/ai/self-driving-lab). Print-layer camera, then VLM, then parameter fix (LLM-3D Print). — [ScienceDirect](https://www.sciencedirect.com/science/article/pii/S2214860425003926). Print and walk with RL sim-to-real (Text2Robot). — [EurekAlert](https://www.eurekalert.org/news-releases/1080030). FDM print validation after agent DFM edits (AgentsCAD). — [arXiv](https://arxiv.org/html/2607.02448)

### Inferences
- An open niche: a general agent such as Claude Code with build123d/CadQuery, a slicer CLI, an OctoPrint or Klipper API, a camera and a cheap test fixture (load cell or calipers via vision) could close a geometry-revision loop from physical data. I found no one who has published this end to end.
- VLM critics are weak on rotational symmetry and fine features (2607.05573). Analytic and geometric checks should complement render-and-look.

### Gaps
- No quantitative comparison of render-feedback vs. FEA-feedback vs. physical-feedback on the same task was found.
- No cost or latency data was found for physical loops beyond MAMA BEAR's throughput (25K tests since 2021).
