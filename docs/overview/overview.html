A desktop app where you and AI agents design physical parts together, on the same live model, test them in real-world conditions, and send them to your printer.

The first version

The core loop: agent edits → test → you approve → print

Version 1 does one thing end to end. Everything else (assemblies, sketching, heavy studies) builds on top of this loop.

1ConnectOpen an Onshape part. The tree, variables and 3D model mirror into the app.
2AskTell an agent what you want: "it flexes under 5 kg, stiffen it".
3Iterate locallyThe agent tries variations on a copy on your computer. Free, fast, no Onshape calls.
4TestThe simulator checks each version against the environment you picked.
5ApproveYou see the change, the stress result and the cost, then merge into Onshape.
6PrintSlice and send to your Prusa or Bambu, with a final confirm.

Why agents work on a local copy

Onshape allows only 2,500 API calls a year on free and student plans, about 7 a day. If agents edited Onshape directly they would burn that in an afternoon.

So the app keeps a simplified copy of each part, driven by the same Onshape variables. Agents experiment on it for free, and only the winning numbers go back to Onshape, about 3 calls per approved change.

What always needs you

  • Merging a change into Onshape main
  • Touching a face that mates with another part
  • Letting an agent edit a part outside its scope
  • Starting a print
  • Spending paid credits

The simulator is a guide, not a guarantee. Every result says which solver and inputs it used.

Built to official rules

  • Uses Anthropic's official Agent SDK and open agent standards, never leaked code.
  • Users bring their own AI agent or key on the free tier, so AI costs are theirs.
  • No tricks to dodge Onshape's limits; every call is counted and capped.

To confirm with Onshape

If shared as a private app, every user's calls would count against the developer's allowance. Listing in Onshape's App Store should avoid that, but Onshape's own docs disagree with themselves, so this needs confirming before launch. Until then, users connect with their own Onshape keys.

Why the free tier stays cheap
